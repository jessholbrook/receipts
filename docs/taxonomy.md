# Taxonomy

Slugs are what's stored. Labels are what's shown. The canonical list lives in
`lib/taxonomy.ts`; keep this file in sync.

## methods (multi)
`usability_testing` Usability testing · `interviews` User interviews ·
`field_study` Field study / contextual inquiry · `ethnography` Ethnography ·
`diary_study` Diary study · `survey` Survey · `card_sorting` Card sorting / tree testing ·
`concept_testing` Concept / prototype testing · `analytics` Behavioral analytics ·
`experimentation` A/B testing / experimentation · `co_design` Participatory / co-design ·
`journey_mapping` Journey / service mapping · `heuristic_review` Expert / heuristic review ·
`eye_tracking` Eye tracking · `benchmarking` UX benchmarking · `accessibility_research` Accessibility research with disabled users ·
`support_analysis` Support ticket / feedback analysis
