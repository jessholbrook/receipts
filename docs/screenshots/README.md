## Refreshing

1. Use the deployed app or a local instance of the revision being documented. Note which one you used.
2. Use a clean browser session in light mode, with no stored filters or theme preference. Enable Do Not Track to skip custom product events.
3. Set the viewport to the dimensions above at device scale factor 1. Wait for page content, web fonts, and visible images to load.
4. Capture the visible viewport as PNG. For the map, select the first dot and scroll so the map introduction sits below the sticky header; include all four contribution rows and the receipt preview.
5. Replace these files, inspect them for loading states, clipped content, overlays, or error messages, and update the capture date in this file and the root README.
